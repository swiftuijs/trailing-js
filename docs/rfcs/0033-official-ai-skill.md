# RFC 0033: Official AI skill

**Status:** Proposed.
**Kind:** Tooling.
**Release:** Not released; no language or npm release change.
**Dependencies:** RFCs 0025, 0026 and 0029.
**Review:** Maintainer-requested direction; [implementation PR #18](https://github.com/swiftuijs/twill/pull/18).

## Problem and native baseline

General coding agents can mistake Twill for Swift, miss build/checker requirements, or generate proposed syntax against a released compiler. Website documentation alone does not give an agent an installable, task-oriented workflow. Users currently have to assemble their own prompts from the guides.

## Design

Provide one portable Agent Skills directory, `skills/twill`, with a standard `SKILL.md`. It teaches application development, debugging, review and migration: native TS/JS boundaries, supported syntax, resource ownership, output costs, framework integration and project validation. Default examples target the published release baseline recorded in skill metadata. Source prototypes require explicit capability and source-build verification; RFC status alone is insufficient.

Keep the skill self-contained and concise. Repository maintenance rules belong in root `AGENTS.md`, including the requirement to review and update the skill whenever public language, tooling, compatibility, performance or release guidance changes.

The website offers installation instructions for common agents and generates a downloadable skill and Agent Skills discovery index from the canonical file. The v0.2.0 discovery entry uses a relative artifact URL and SHA-256 digest. GitHub and website installation deliver the same instructions. No separate npm skill package or application runtime is introduced.

## Compatibility and ecosystem boundaries

Installation uses the third-party open `skills` CLI or a manual directory copy. Agent support for discovery and activation follows each client's implementation. Installing instructions does not install the compiler, editor, framework or project dependencies and does not provide a correctness proof.

Skills may evolve independently of a language release while retaining a published language baseline. A coordinated version change updates that metadata. Existing application code, compiler output and APIs are unaffected.

## Costs and validation

The skill adds text to an agent's context and small static site assets. It introduces no application allocation, scheduling, wrapper or runtime dependency. Verify metadata and release baseline, official documentation links, executable/type-checkable examples, formatter compatibility, generated bytes/digest and deployment under root and subpath hosting. Exercise the real skills CLI against a local repository source and a served website, in temporary application directories.

CI checks skill conformance/examples after the compiler build; docs build/dev regenerates the downloadable instructions. `AGENTS.md` and contribution/release guides describe ongoing synchronization. Implementation completion and proposal acceptance remain separate maintainer decisions.
